# Hyprland 0.56 Lua config

Caelestia-based Hyprland config for **Hyprland 0.56** (Aquamarine backend, Lua config).
`hyprland.lua` is the only entry point. The old `hyprland.conf` / `modules/*.conf` tree is gone.

## Why this rewrite

Hyprland 0.55 replaced hyprlang with Lua. `hyprland.conf` still loads for a release or two,
then it is dropped. The old conf stack was also fighting 0.56 bind/global-shortcut changes
(Super-tap launcher, Electron stealing screenshot chords).

This repo is the live tree behind `~/.config/hypr` (symlink into Caelestia share).

## Layout

| Path | Role |
|------|------|
| `hyprland.lua` | Entry. Copies scheme, merges `hypr-vars.lua`, loads modules, then machine files |
| `variables.lua` | Apps, gaps, colours, every keybind name |
| `hyprland/` | Env, look, input, autostart, rules, binds, gestures |
| `utils/` | Workspace groups, PiP, special-ws toggles |
| `scheme/default.lua` | Material You fallback; `current.lua` is generated |
| `scripts/monitor-setup.sh` | Writes `~/.config/caelestia/hypr-monitors.lua` |

## Personal overrides (not in this repo)

Do not edit files here for day-to-day tweaks. Put them in:

- `~/.config/caelestia/hypr-vars.lua` — override any key from `variables.lua`
- `~/.config/caelestia/hypr-user.lua` — extra binds, rules, last-word config
- `~/.config/caelestia/hypr-nvidia.lua` — NVIDIA env / cursor
- `~/.config/caelestia/hypr-monitors.lua` — generated by `monitor-setup.sh`

Example `hypr-vars.lua`:

```lua
return {
    browser = "librewolf",
    kbClearNotifs = "SUPER + C",
}
```

## Shortcuts that stay yours

- Super tap: Caelestia launcher (IPC on key release, not GlobalShortcut)
- Super+C clear notifications, Super+Ctrl+C editor
- Super+T/W/E/G/Q terminal, LibreWolf, Thunar, GitHub Desktop, close
- Super+Shift+T Telegram, Super+D Equibop/comms scratchpad
- Super+Shift+S and Ctrl+Shift+S region screenshot → clipboard
- Super+Z / Super+X move / resize (also Super + LMB / RMB)
- US/RU via Super+Space

Cheat sheet: `~/.config/caelestia/KEYBINDS.md`.

## Monitors

Layout is **not** bound to `DP-3` / `HDMI-A-1`. NVIDIA renames those.

| Panel | How it is matched | Placement |
|-------|-------------------|-----------|
| Dell P2421DC | EDID `desc:Dell Inc. DELL P2421DC` | 2560x1440 @ left `0x0` |
| LG HDR 4K | EDID `desc:LG Electronics LG HDR 4K` | 3840x2160 @ right `2560x0` |
| Chimei Innolux laptop | EDID `desc:Chimei Innolux Corporation 0x15F5` | 1920x1080 @ 1.5 scale |

`hyprland/monitors.lua` reapplies this on start and whenever a display is added or removed. If both desk panels are present, the laptop panel is disabled so it cannot steal the origin.

Manual nudge if something is still wrong: `~/.config/hypr/scripts/monitor-setup.sh`

Do **not** put `monitor = DP-3,...` in `hypr-monitors.lua`. That file is for extras only.

## Reload

Save a Lua file, or `hyprctl reload`. Env and NVIDIA vars need a new session.
